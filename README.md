# 斯洛維尼亞・布萊德城堡（Bled Castle / Blejski grad）深度走讀與數位策展

本專案為【數位策展深旅系列：極東義大利與斯洛維尼亞邊境】所打造的沉浸式互動走讀 Web 應用程式。

---

## 🏰 城堡概況與走讀價值
- **歷史座標**：西元 1004 年神聖羅馬帝國皇帝亨利二世封贈，1011 年文獻首次記載，斯洛維尼亞最古老之城堡。
- **地理絕壁**：高聳於距布萊德湖面 **130 公尺** 的垂直冰蝕石灰岩峭壁上，俯瞰湖心島與朱利安阿爾卑斯山（Julian Alps）。
- **建築風格**：自羅馬防禦塔起建，經 1511 年大地震後修復，現存建築融合羅馬式、哥德式與巴洛克式雙層庭院佈局。

---

## 🌟 八大核心走讀站點（8 Curated Walking Stops）
1. **入堡吊橋與外層哥德城門 (Bridge & Outer Defense Gate)**：橫跨乾壕的中世紀防禦前哨。
2. **古騰堡木製印刷工坊 (Castle Printing Shop)**：體驗 16 世紀活字排版與手工羊皮紙壓印。
3. **方濟會修士酒窖 (Castle Cellar & Wine Wax Sealing)**：修士侍酒師引導橡木桶取酒與火漆封蠟。
4. **阿爾卑斯草本藝廊 (Herbal Gallery & Apiculture)**：卡尼鄂拉蜂、彩繪蜂箱板與高山草藥文化。
5. **聖阿爾博因與聖英格曼小教堂 (Gothic Chapel)**：16世紀哥德教堂與巴洛克錯視壁畫（Trompe-l'œil）。
6. **城堡歷史博物館 (Castle Museum)**：青銅時代孔雀胸針、斯拉夫墓葬與中世紀騎士文物。
7. **世界最古老葡萄藤後代 (Descendant of Maribor's Old Vine)**：450年樹齡老藤在古石牆的生機。
8. **絕壁天際露台與奶油蛋糕 (Panoramic Terrace & Kremšnita)**：俯瞰湖心島全景，品嚐 7x7cm 傳奇奶油蛋糕。

## 🚀 網頁功能特色
- **沉浸式地圖導覽**：整合 Leaflet 地圖與地標雙向聯動，點選站點即時定位。
- **中文語音伴讀導遊 (TTS)**：支援 Web Speech API，可隨走隨聽各站點背景歷史與私房攝影視角。
- **活態互動模擬器**：
  - 古騰堡活版拓印文憑模擬（可自訂旅人姓名印製）。
  - 修士酒窖火漆封蠟儀式模擬（主教紅蠟 / 皇家金蠟）。
- **三種主題路線篩選**：30分鐘精華打卡線、60分鐘人文歷史線、浪漫工藝感官線。
- **響應式美學設計**：深色典雅中世紀羊皮紙質感 UI，適配手機與桌面瀏覽。
